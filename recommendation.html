How Model 1 (KNN) Works in this Mini Project

Each food item is mapped to a vector in $\mathbb{R}^d$ comprising one-hot cuisine encodings, weighted taste coefficients (Mild=0.0, Medium=1.5, Spicy=3.0), dietary constraints (Vegetarian weight 3.0), and normalized ratings. When the user submits preferences, Scikit-learn's NearestNeighbors computes the cosine angle distance: $$\text{Cosine Similarity}(u, v) = \frac{u \cdot v}{\|u\|_2 \|v\|_2}$$ and returns the top $K$ nearest neighbors with the highest taste compatibility score.
